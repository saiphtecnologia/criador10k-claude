# Criador 10K · Máquina de Conteúdo para Claude

Plugin e Skill editorial para transformar conteúdos, links, transcrições e insights em carrosséis para Instagram com o método Criador 10K.

## O que faz

O agente conduz briefing, headlines, espinha dorsal, copy por slide, fechamento e revisão editorial.

A montagem visual, imagens e identidade final permanecem na Máquina de Conteúdo:
https://maquina.criador10k.com.br

## Formas de usar

### Claude Plugin
Quando aprovado no diretório público do Claude, instale o plugin diretamente pelo diretório.

Plugins do Claude estão disponíveis em planos pagos.

### Claude Skill
Usuários que preferem a Skill standalone podem baixar o ZIP da release deste repositório e instalar em:

Personalizar → Skills → + → Criar skill → Carregar um skill

Skills personalizadas também estão disponíveis no plano Free, com execução de código habilitada.
## Exemplos

- "Quero transformar um conteúdo existente em carrossel."
- "Tenho um insight e quero criar uma narrativa."
- "Revise esta copy com o método Criador 10K."

## Privacidade e integrações

Este plugin não possui MCP, API externa, autenticação própria, tracking ou coleta de dados.

Ele contém apenas uma Agent Skill e arquivos editoriais de referência.

## Estrutura

```text
.claude-plugin/plugin.json
skills/
  criar-carrosseis-criador10k/
    SKILL.md
    references/
```
