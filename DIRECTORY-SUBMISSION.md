https://github.com/saiphtecnologia/criador10k-claude/blob/main/PRIVACY.md

Conta de teste:
Não aplicável. O plugin não possui login, servidor remoto, API externa ou dados privados.
Exemplos de teste:
1. "Quero transformar um conteúdo existente em carrossel."
2. "Tenho um insight e quero criar uma narrativa."
3. "Revise esta copy com o método Criador 10K."

Dados coletados:
Nenhum dado é coletado pelo plugin.

Nenhuma.

Não utiliza.

Finalidade:
Conduzir briefing editorial, gerar headlines, estruturar narrativa e escrever copy por slide. A montagem visual é feita separadamente na Máquina de Conteúdo.

Observação de acesso:
O Plugin do diretório exige um plano pago do Claude. A Skill standalone da mesma release pode ser instalada por usuários Free com execução de código habilitada.
