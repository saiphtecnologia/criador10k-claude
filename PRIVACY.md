# Privacy

Criador 10K · Máquina de Conteúdo for Claude contains no remote MCP server, tracking script, analytics SDK, external authentication, or data-collection endpoint.

The plugin itself does not transmit user prompts, generated content, files, or account information to Saiph Tecnologia.

User interactions remain subject to the privacy and data-handling terms of the Claude product where the plugin or Skill is used.
